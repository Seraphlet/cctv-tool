# 央视舆情模块化生成器（cctv-tool）

一个用于日常新闻监测、舆情/正面内容整理和模板化文本交付的浏览器工作台。整合内容生成、解析、拼接、速查表及临时资料，减少在不同工具间切换。

> **说明**：本项目为个人开发的效率工具，非央视官方产品，也不代表央视立场。目前以保留稳定版本为主，暂无持续更新计划。

**入口**：[GitHub 仓库](https://github.com/Seraphlet/cctv-tool) · [旧版页面（备选）](https://noahanna.online/files/cctv-tool.bak/)

## 主要功能

| 功能 | 作用 |
| --- | --- |
| 日常 / 全套监测 | 录入频道、栏目、播出时间、内容、标题、摘要或全文等，按模板生成并复制文本 |
| 舆情 / 正面 | 监测类别切换，分别使用红色/绿色的标题和复制提示 |
| 解析 / 内容拼接 | 文本解析与内容拼接，提供主工作区快捷入口 |
| 文本阅读 / 新闻搜索 | 文本阅读、新闻搜索等独立工具 |
| 速查表 | 频道节目表、常用语句、人员班表；支持班表批量粘贴导入和 CSV 导出 |
| 待办提醒 / 时间工具 | 待办、时间累加与时间差计算 |
| 随手记 / 图片暂存板 | 右侧小窗及全屏工具，保存临时笔记和图片 |
| 快捷网址 | 预设常用入口，用户可以添加、修改、删除 |
| 组件设置 | 模板编辑、默认配置、恢复配置，以及分类弹窗/复制反馈等设置 |

## 使用方法

1. 进入页面后按需要选择「舆情」或「正面」，也可以跳过；是否显示首次选择弹窗可以在组件设置里更改。
2. 选择「日常」或「全套监测」，填写相关字段并复制提示或补充内容；复制成功提示可独立关闭。
3. 点击「解析」或「内容拼接」访问对应工具；点击**顶部蓝色 Logo** 可以直接返回「日常」。
4. 其他模块在左侧导航抽屉中。右侧工具栏可打开随手记、图片暂存板、快捷网址与设置，关闭小窗后工作区恢复宽度。

### 一次性导入整张班表

进入 **速查表 → 班表 → 整张班表导入**：

1. 在 Excel 或腾讯文档选中包含**姓名、日期、班次**的连续区域并复制。
2. 粘贴到导入窗口，点击「识别并预览」，核对姓名、日期和班次。
3. 选择「替换整张班表」或「同月合并（只更新非空格）」，确认后写入。

提供「整块粘贴」及「Index / Columns / Data 精确导入」两种模式。精确导入分别粘贴姓名列、日期行和对应班次矩形：行中空格保留，行尾补齐空值，缺失整行或列数超出则阻止导入。整块粘贴仍支持常见的 Tab 分隔文本、CSV、带「排班需求」辅助列和星期行的表格。只复制部分日期时，导入器会自动生成当月其他日期的空列。**复杂合并单元格或跨月数据请先核对预览，覆盖之前建议导出 CSV 备份。** 原有单行导入仍可用。

## 本地启动与部署

项目使用原生 **HTML / CSS / JavaScript**，无需 npm 安装、编译或数据库服务器。克隆项目后使用静态 HTTP 服务器即可：

~~~bash
git clone https://github.com/Seraphlet/cctv-tool.git
cd cctv-tool
python3 -m http.server 8000
~~~

打开浏览器访问 **http://localhost:8000/**。也可将代码原样部署到静态站点服务器，保持入口、样式、脚本和 modules 目录的相对路径不变。

> 不建议直接通过 file:// 打开 HTML：动态模块加载及剪贴板功能可能受到浏览器限制。剪贴板和通知功能可能需要 HTTPS 或 localhost、权限及较新版本的浏览器。

## 目录结构

~~~text
cctv-tool/
├── index.html                # HTML 入口与工作台
├── core.js                   # 主模块注册、事件、基础业务
├── style.css                 # 原有样式
├── ui-workspace.js           # 侧栏、快捷网址、界面交互
├── ui-workspace.css          # 新版 UI 与响应式样式
└── modules/
    ├── yuqing-module.js     # 日常 / 全套监测
    ├── extract-module.js    # 解析
    ├── pingjie-module.js    # 内容拼接
    ├── reader-module.js     # 文本阅读
    ├── news-module.js       # 新闻搜索
    ├── quickboard-module.js # 速查表与班表
    ├── schedule-import.js   # 班表批量粘贴导入
    ├── calc-module.js       # 时间工具
    ├── reminder-module.js   # 待办提醒
    ├── builder-module.js    # 模板构建
    ├── image-pad.js         # 图片工具模块文件
    └── scratchpad-module.js # 笔记工具模块文件
~~~

模块按需加载；部分右侧悬浮工具的实际实现位于 core.js。开发时请先确认使用中的入口文件。

## 数据与隐私

- 笔记、模板、快捷网址和 UI 偏好等使用浏览器的 **localStorage**；图片暂存板和速查表使用 **IndexedDB**。
- 本地数据保存在当前浏览器与当前站点来源（origin），**不会随 GitHub 提交、换设备或换域名自动同步**。
- 清除站点数据、无痕模式或浏览器重装可能导致内容丢失，请自行备份重要信息。
- 外部网站/新闻检索依赖相关平台的可用性，可能需要联网与登录。
- .gitignore 只决定 Git 忽略哪些文件，并不能备份或恢复浏览器中的数据。
